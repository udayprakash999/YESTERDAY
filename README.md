# YESTERDAY
- YESTERDAY.exe is a simple horror theme  terminal game. it looks like an old terminal where users can type commands and discover hidden memories.

# Demo
[play YESTERDAY.exe](https://udayprakash999.github.io/YESTERDAY/)

# Tech Stack 
- HTML 
- CSS
- JavaScript
- Google Fonts

# Features 
- Old Theme style design
- Green Glowing Text
- Users Can Type Commands To Play The Game
- Hidden Files And Secret Messages
- Password to unlock files
- Game progress is saved automatically
- Game status check
- Three different ending
- command history feature
- Reset to start the game again Feature 

# How To Play

1. open the game in your browser
2. Type help command to see all commands
3. try different commands to explore the terminal
4. find hidden files and unlock them using password
5. read the secret msg and discover the story
6. choose your ending : FORGIVE / STAY / SHUTDOWN
